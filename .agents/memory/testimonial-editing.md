name: Testimonial editing
description: Editorial direction for incorporating participant reviews.
---

The user permits editorial selection and shortening of long testimonials. Consider existing reviews and vary the excerpts to highlight as many dimensions of the course as possible. Participant photos should be cropped as face shots; they need not be perfect or extremely detailed, but should indicate real people.

**Why:** The user explicitly requested this approach and expects to supply additional testimonials.

**How to apply:** Preserve each review's meaning and attribution; select faithful excerpts rather than inventing praise. Use only supplied portraits and balance new reviews against existing voices.

Attribute testimonials by name only, without “Cohort 1” or “Cohort 2” labels.

**Why:** The user explicitly requested removing cohort labels from all testimonials.

**How to apply:** Keep names without cohort suffixes. Where a review has no supplied name, preserve anonymity rather than inventing one.
