---
name: Navigation order
description: User's requirement for ordering this site's section navigation.
---

Keep section navigation links in the same order as their target sections down the page.

**Why:** The user asked that the tabs “move down the page sequentially, not jump back and forth.”

**How to apply:** When adding links or rearranging sections, check the order together on desktop and mobile. Keep the interest button's existing form-opening behavior.
