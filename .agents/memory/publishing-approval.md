name: Publishing approval
description: User approval is required before forwarding this site's changes to Netlify.
---

Do not send changes to Netlify until the user approves. Keep work in the local preview and do not push to the GitHub deployment branch without that approval.

**Why:** The user explicitly requested approval before changes go to Netlify to save credits there.

**How to apply:** Finish and verify changes in the preview first. State that they have not been published. Wait for explicit approval before any push that triggers the site's Netlify build.
